🎯 QuizMaster – Interactive Quiz Game

QuizMaster is a simple and interactive quiz game created by Maria Kareem. It helps users test their knowledge in different subjects while having fun.

The project is designed with a clean interface, a blue and teal theme, and features that make learning more enjoyable.

✨ Features

- 📚 Five Subjects: Choose from different subjects.
- 🎚️ Three Difficulty Levels: Easy, Medium, and Hard.
- ⏱️ Timed Questions: Answer questions within the given time.
- 🏆 Score System: Get points for correct answers.
- 💡 Answer Explanations: Learn why an answer is correct.
- 📝 Answer Review: Review your answers after completing the quiz.
- 📱 Mobile-Friendly Design: Play on mobile phones and computers.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🚀 How to Play

1. Open the QuizMaster website.
2. Choose your preferred subject.
3. Select a difficulty level.
4. Read each question carefully.
5. Select your answer before the timer ends.
6. Complete the quiz and check your score.
7. Review your answers and learn from your mistakes.

💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Start playing!

No server or additional installation is required.

🎓 Purpose of the Project

I created QuizMaster to practice my programming skills and learn how to build an interactive website using HTML, CSS, and JavaScript. This project helped me understand how to design a user interface, manage quiz logic, calculate scores, and make a website more engaging.
